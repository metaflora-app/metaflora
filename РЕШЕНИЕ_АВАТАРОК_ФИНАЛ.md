Instagram блокирует прямую загрузку изображений с их CDN в сторонние приложения.

## ✅ РЕШЕНИЕ

### 1. Backend: Прокси endpoint

**Файл:** `/Users/user/Desktop/metaflora-service/app/api/proxy-image/route.ts`

**Что делает:**
- Принимает Instagram CDN URL как параметр `?url=...`
- Загружает изображение на сервере (без CORS ограничений)
- Возвращает изображение с правильными CORS headers
- Кеширует на 24 часа

**Endpoint:** `https://service-production-f0b1.up.railway.app/api/proxy-image?url=...`

### 2. Frontend: Конвертация URL

**Файл:** `src/utils/labaApi.ts`

**Функция:**
```typescript
export function convertInstagramImageUrl(url: string | null | undefined): string | null {
  if (!url || url === '') return null;
  
  // Если это Instagram CDN - проксируем через наш сервер
  if (url.includes('cdninstagram.com') || url.includes('instagram.com')) {
    return `${API_URL}/api/proxy-image?url=${encodeURIComponent(url)}`;
  }
  
  return url;
}
```
