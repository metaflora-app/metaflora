## 🐛 Troubleshooting

### Проблема: Контент не отображается

**Решение 1:** Очистить кеш
```javascript
// В консоли браузера (F12)
localStorage.clear();
location.reload();
```

**Решение 2:** Проверить is_active
```sql
-- В Supabase SQL Editor
SELECT * FROM workshop_prompts WHERE is_active = false;
-- Если есть записи, обновить:
UPDATE workshop_prompts SET is_active = true WHERE id = 'ID';
```

**Решение 3:** Проверить CORS
- API должен возвращать заголовки CORS
- Проверить в Network tab (F12)

### Проблема: Ошибка при загрузке файла

**Причины:**
1. Файл слишком большой (макс 5MB для обложек)
2. Неправильный формат (только PNG/JPG/WebP)
3. Бакет не создан в Supabase Storage

**Решение:**
1. Сжать картинку
2. Конвертировать в PNG/JPG
3. Проверить бакеты в Supabase Dashboard → Storage
