**Файл**: `app/api/laba/top-reels/route.ts`

**Старая логика** (НЕ РАБОТАЛА):
```typescript
// Использовал foreign key select

```

**Новая логика** (РАБОТАЕТ):
```typescript
// ПРЯМОЙ JOIN через inner
.select(`
  id,
  instagram_reel_id,
  ...все поля...,
  laba_top_reels!inner (
    position,
    category
  )
`)
.eq('laba_top_reels.category', category)
.order('laba_top_reels.position', { ascending: true })
```

**Преимущества**:
- ✅ Нет парсинга массивов
- ✅ Прямой доступ к полям laba_reels
- ✅ Правильная сортировка по position
- ✅ Простой и понятный код

#### 2. Academy Lessons API
**Файл**: `app/api/content/academy-lessons/[id]/route.ts`

**Добавлено**:
```typescript
// Обработка content_blocks для изображений
if (data && data.content_blocks) {
  let blocks = data.content_blocks;
  
  // Парсим если строка
  if (typeof blocks === 'string') {
    blocks = JSON.parse(blocks);
  }
  
  // Обрабатываем каждый блок
  if (Array.isArray(blocks)) {
    blocks = blocks.map((block: any) => {
      if (block.type === 'image' && block.content) {
        // Проверка Supabase URL
        if (block.content.includes('supabase.co')) {
          return block;
        }
      }
      return block;
    });
    
    data.content_blocks = blocks;
  }
}
```

**Что это даёт**:
- ✅ Парсинг JSON если content_blocks строка
- ✅ Обработка image блоков
- ✅ Проверка Supabase URLs
- ✅ Подготовка для CORS headers

### Supabase JOIN синтаксис

**Правильный способ** (используется сейчас):
```typescript
.select(`
  field1,
  field2,
  related_table!inner (
    related_field1,
    related_field2
  )
`)
.eq('related_table.filter_field', value)
```

**Неправильный способ** (использовался раньше):
```typescript
.select(`
  field1,
  field2,
  related_table (
    related_field1,
    related_field2
  )
`)
// Потом парсинг массивов в коде
```
