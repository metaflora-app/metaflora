## 🤖 API ДЛЯ БОТА

### Файл: `app/api/bot/send-materials/route.ts`

**Требования:**
- `TELEGRAM_BOT_TOKEN` в Railway Variables
- `userId` от Telegram WebApp (не 'unknown')

**Логика:**
```typescript
export async function POST(request) {
  const { materials, lessonTitle, userId } = await request.json();
  
  // Проверки
  if (!botToken) return error 'Bot token not configured';
  if (userId === 'unknown') return error 'User ID not available';
  
  // Отправка через Telegram API
  for (const material of materials) {
    await fetch(`https://api.telegram.org/bot${botToken}/sendMessage`, {
      body: JSON.stringify({
        chat_id: userId,
        text: `📎 *${lessonTitle}*\n\n📄 ${material.name}\n🔗 ${material.url}`,
        parse_mode: 'Markdown'
      })
    });
  }
  
  return { success: true, results };
}
```

**Формат materials:**
```json
[
  {"name": "файл.pdf", "url": "https://...", "size": "1.2 MB"}
]
```

## 🎯 КРИТИЧНЫЕ ДЕТАЛИ

### 1. is_active флаг:
- **Маленькая карточка:** создает с `is_active: false`
- **Большая карточка:** при деплое ставит `is_active: true`
- **Мини-апп:** загружает только `is_active: true`

### 2. Async onClick в academy-video:
```typescript
// ПРАВИЛЬНО:
onClick={async () => {
  await handleSave();
  window.location.href = '/next';
}}

// НЕПРАВИЛЬНО:
onClick={() => {
  handleSave(); // Не ждет!
  window.location.href = '/next';
}}
```

### 3. Materials в content_blocks:
```typescript
// Перед деплоем
let finalContentBlocks = [...contentBlocks];
if (materials.length > 0) {
  finalContentBlocks.push({
    id: Date.now().toString(),
    type: 'materials',
    content: JSON.stringify(materials) // Обязательно JSON.stringify!
  });
}
```

### 4. Разделение заголовков:
- `video_title` - заголовок видео (из academy-video)
- `title` - заголовок урока (из academy-card-large)
- В мини-аппе video экран показывает `video_title || title`
- В мини-аппе materials экран показывает `title`
