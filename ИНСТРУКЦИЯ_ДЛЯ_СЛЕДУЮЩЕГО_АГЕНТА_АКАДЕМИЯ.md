## 🎯 СЛЕДУЮЩАЯ ЗАДАЧА: АКАДЕМИЯ

### Структура Академии:

```
АКАДЕМИЯ
├── Курсы (4 категории)
│   ├── Система
│   ├── Искусство
│   ├── Промптинг
│   └── Автоматизация
│
└── Каждый курс содержит:
    ├── Уроки (academy_lessons)
    │   ├── Номер урока
    │   ├── Заголовок
    │   ├── Описание
    │   ├── Обложка
    │   ├── Аннотация
    │   ├── Промпт
    │   └── Материалы
    │
    └── Видеоуроки (academy_videos)
        ├── ID урока
        ├── Заголовок
        └── URL видео
```

### Таблицы Supabase:

**1. academy_courses:**
```sql
- id (uuid, PK)
- course_type (text) -- 'система' | 'промптинг' | 'искусство' | 'автоматизация'
- title (text)
- description (text, nullable)
- cover_image_url (text, nullable)
- is_active (boolean)
- order_index (int)
- created_at (timestamp)
- updated_at (timestamp)
```

**2. academy_lessons:**
```sql
- id (uuid, PK)
- course_id (uuid, FK → academy_courses)
- lesson_number (int, nullable)
- title (text)
- description (text, nullable)
- cover_image_url (text, nullable)
- annotation (text, nullable)
- prompt_text (text, nullable)
- materials (jsonb, nullable) -- [{name, url, size}]
- filter_tags (text[], nullable)
- keywords (text[], nullable)
- is_active (boolean)
- order_index (int)
- created_at (timestamp)
- updated_at (timestamp)
```

**3. academy_videos:**
```sql
- id (uuid, PK)
- lesson_id (uuid, FK → academy_lessons)
- title (text)
- video_url (text, nullable)
- is_active (boolean)
- created_at (timestamp)
- updated_at (timestamp)
```
