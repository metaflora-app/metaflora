**Где:** При создании урока в академии через сервис

**Причина:** В Supabase есть ссылка на удаленную таблицу `academy_lesson_files`

### Где искать:

1. **Supabase SQL Editor:** https://supabase.com/dashboard/project/lwjsbflvsmscfrdkejia/sql

2. **Проверить триггеры:**
```sql
SELECT tgname, tgrelid::regclass, proname
FROM pg_trigger
JOIN pg_proc ON pg_trigger.tgfoid = pg_proc.oid
WHERE tgname LIKE '%lesson%' OR proname LIKE '%lesson%';
```

3. **Проверить views:**
```sql
SELECT table_name, view_definition
FROM information_schema.views
WHERE table_schema = 'public'
AND view_definition LIKE '%academy_lesson_files%';
```

4. **Проверить foreign keys:**
```sql
SELECT
    conname AS constraint_name,
    conrelid::regclass AS table_name,
    confrelid::regclass AS foreign_table
FROM pg_constraint
WHERE confrelid = 'academy_lesson_files'::regclass;
```

5. **Проверить RLS политики:**
```sql
SELECT schemaname, tablename, policyname, permissive, roles, cmd, qual, with_check
FROM pg_policies
WHERE qual::text LIKE '%academy_lesson_files%'
   OR with_check::text LIKE '%academy_lesson_files%';
```

### Как исправить:

- Если найден триггер → `DROP TRIGGER trigger_name ON table_name;`
- Если найден view → `DROP VIEW view_name;`
- Если найден foreign key → `ALTER TABLE table_name DROP CONSTRAINT constraint_name;`
