# 🚀 БЫСТРАЯ ИНСТРУКЦИЯ - Проверка Supabase

## 1. Переключись на схему PUBLIC в Supabase:

На скриншоте ты в схеме `auth` - там служебные таблицы Supabase.

**Нужно переключиться:**
1. В Supabase Dashboard → Table Editor
2. Вверху слева где написано "schema auth" - **кликни на это**
3. Выбери **"public"** из списка
4. Теперь ты увидишь таблицы `users` и `metacoins_transactions`

## 2. Проверь таблицу users:

1. Кликни на таблицу `users`
2. Посмотри, есть ли там записи
3. Если есть - посмотри на `metacoins_balance` - он должен обновляться

## 3. Проверь таблицу metacoins_transactions:

1. Кликни на таблицу `metacoins_transactions`
2. Посмотри, есть ли там записи
3. Если нет - значит транзакции не создаются (RLS блокирует)

## 4. Если таблицы пустые - отключи RLS:

Открой SQL Editor:
```
https://supabase.com/dashboard/project/lwjsbflvsmscfrdkejia/sql/new
```

Выполни:
```sql
ALTER TABLE users DISABLE ROW LEVEL SECURITY;
ALTER TABLE metacoins_transactions DISABLE ROW LEVEL SECURITY;
```

## 5. Протестируй TEST_SUPABASE.html:

Открой файл (уже должен быть открыт):
```bash
open /Users/user/.cursor/worktrees/_________/lct/TEST_SUPABASE.html
```

Нажми кнопки по порядку и смотри логи.
