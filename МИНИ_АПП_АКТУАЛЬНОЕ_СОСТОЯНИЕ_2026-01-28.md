## 🎯 ВАЖНЫЕ ДЕТАЛИ

### 1. Параметр type в URL:

**Для видео:**
```
/academy-lesson-video?lesson={id}&type=academy
/academy-lesson-video?lesson={id}&type=demo
```

**Для материалов:**
```
/academy-lesson-materials?lesson={id}&type=academy
/academy-lesson-materials?lesson={id}&type=demo
```

**Зачем:**
- `type=academy` → отслеживается прогресс
- `type=demo` → НЕ отслеживается прогресс
- Используются разные API (getAcademy* vs getDemo*)

### 2. Навигация между экранами:

**Из списка уроков:**
```typescript
onClick={() => navigate(`/academy-lesson-video?lesson=${lesson.id}`)}
// Автоматически type=academy
```

**Из видео в материалы:**
```typescript
onClick={() => navigate(`/academy-lesson-materials?lesson=${lessonId}&type=${lessonType}`)}
// Передает type дальше
```

### 3. Фильтры и поиск:

**В prompt-first (цех):**
- Фильтры: новое, топ-выбор, недавние, избранное

## 🔄 LIFECYCLE УРОКА

### Создание и публикация:

1. **Сервис:** academy-*-card-small
   - Вводим номер урока и description
   - Нажимаем "видео"
   - POST `/api/content/academy-lessons` с **is_active: false**
   - Сохраняем lesson_id в localStorage
   - → academy-video

2. **Сервис:** academy-video
   - Вводим video_title и video_url
   - Нажимаем "карточка"
   - PATCH урока (video_title)
   - POST видео в academy_videos
   - → academy-card-large

3. **Сервис:** academy-card-large
   - Вводим title урока
   - Добавляем content_blocks
   - Добавляем materials (если есть)
   - Нажимаем **ДЕПЛОЙ**
   - PATCH урока с **is_active: true** ← ВАЖНО!
   - → урок появляется в мини-аппе

### Просмотр в мини-аппе:

4. **Мини-апп:** academy-course-*
   - Видим карточку урока (description)
   - Нажимаем "перейти"
   - → academy-lesson-video?lesson={id}

5. **Мини-апп:** academy-lesson-video
   - Смотрим видео
   - При 80% → videoWatched = true
   - Нажимаем "получить материалы"
   - → academy-lesson-materials?lesson={id}

6. **Мини-апп:** academy-lesson-materials
   - Читаем контент (text, image, prompt)
   - Скроллим до конца (95%) → materialsRead = true
   - Если оба условия → урок в completed
   - Нажимаем "скачать файлы" → отправка в бота

7. **Мини-апп:** academy-courses-all
   - Возвращаемся на главный экран
   - Видим обновленные индикаторы
   - Видим новый процент пройденных уроков
