## ⚠️ Что нужно сделать

### 1. Настроить Telegram Bot Token
Добавить в Railway переменную окружения:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

Без этого уведомления в Telegram не будут работать.

### 2. Настроить cron на Railway
1. Открыть Railway Dashboard
2. Проект `metaflora-service`
3. Settings → Cron Jobs
4. Добавить:
   - Schedule: `0 12 * * *` (каждый день в 12:00 UTC)
   - Command: `curl https://service-production-f0b1.up.railway.app/api/cron/update-tracked-reels`

### 3. Проверить video_id в БД
Если видео не отображается в AcademyLessonVideoScreen:
1. Проверить таблицу `academy_videos` в Supabase
2. Убедиться что `video_id` сохранен
3. Проверить логи Railway backend

### 4. Протестировать отслеживание
1. Добавить аккаунт через `/laba-search-account`
2. Проверить что reels появились в `/laba-tracked`
3. Запустить cron вручную:
   ```bash
   curl https://service-production-f0b1.up.railway.app/api/cron/update-tracked-reels
   ```

3. Проверить что URL видео публичный (доступен без авторизации)

**Решение**: Добавлено логирование в `app/api/kinescope/upload/route.ts`
