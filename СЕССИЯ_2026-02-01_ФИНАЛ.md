### 2. Top-reels Cron - ИСПРАВЛЕН ✅
**Проблема**: 
- Второй скрапер (Instagram) не запускался из-за падения на `video_url NOT NULL`
- Cron использовал ротацию категорий вместо "нейросети"

**Решение**:
- Добавлен fallback для `video_url`: `reel.videoUrl || reel.displayUrl || reel.url`
- Фильтрация невалидных reels перед записью в БД
- Исправлен баг: брал `ownerUsername` из `reelsData`, теперь `account_username` из `savedReels`
- Добавлен query параметр `?category=нейросети` для явного указания категории

**Файлы**: 
- `lib/apify.ts` - fallback для video_url
- `app/api/cron/update-top-reels/route.ts` - фильтрация + query param

**Коммиты**: `54afcfe`, `539d49c`, `6055af0`
