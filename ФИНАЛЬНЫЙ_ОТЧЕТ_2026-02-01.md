### 3. ✅ PNG→JPEG конвертер для изображений
**Файлы**:
- `src/utils/imageConverter.ts` - новая утилита
- `src/screens/academy-lesson-materials/AcademyLessonMaterialsScreen.tsx`
- `src/screens/article/ArticleScreen.tsx`

**Что сделано**:
```typescript
// Автоматическая конвертация PNG → JPEG
const imageUrl = convertPngToJpeg(block.content);

// Fallback на PNG если JPEG не найден
<img
  src={imageUrl}
  onError={(e) => {
    const target = e.target as HTMLImageElement;
    if (target.src !== block.content) {
      target.src = block.content; // Fallback на PNG
    }
  }}
/>
```

**Логика**:
1. Заменяет `.png` на `.jpeg` в URL
2. Если JPEG не найден (404) → автоматически загружает PNG
3. Работает только для Supabase URLs
4. `crossOrigin="anonymous"` для CORS

### PNG→JPEG конвертация
```typescript
export function convertPngToJpeg(pngUrl: string): string {
  if (!pngUrl.includes('supabase.co')) return pngUrl;
  
  if (pngUrl.endsWith('.png') || pngUrl.endsWith('.PNG')) {
    return pngUrl.replace(/\.png$/i, '.jpeg');
  }
  
  return pngUrl;
}
```

### Fallback на PNG
