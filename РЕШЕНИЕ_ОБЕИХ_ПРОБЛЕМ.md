### 2. ✅ Подписчики через instagram-scraper (пакетно)

**Было:** Вызов `instagram-profile-scraper` для КАЖДОГО username отдельно
- Медленно (N запросов)
- Дорого
- Может таймаутить

**Решение:** Используем `instagram-scraper` с `directUrls` - ОДИН запрос для ВСЕХ профилей

```typescript
// Формируем URLs всех профилей
const profileUrls = uniqueUsernames.map(u => `https://www.instagram.com/${u}/`);

// ОДИН запрос для ВСЕХ профилей
const run = await apifyClient.actor('apify/instagram-scraper').call({
  directUrls: profileUrls,
  resultsType: 'details',  // Получаем детали профиля
  resultsLimit: 1,
});

// Получаем результаты
const { items } = await apifyClient.dataset(run.defaultDatasetId).listItems();

// Заполняем map
for (const item of items) {
  profilesMap.set(item.username, {
    followers: item.followersCount || 0,
    profilePic: item.profilePicUrl || '',
  });
}
```

**Преимущества:**
- ✅ ОДИН запрос вместо N запросов
- ✅ Гораздо быстрее
- ✅ Дешевле
- ✅ Не таймаутит
