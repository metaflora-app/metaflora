### 2. ✅ Cron перезагружает все reels вместо добавления новых

**Решение:** 
Логика крона ПРАВИЛЬНАЯ - он уже фильтрует только новые reels:

```typescript
// Получаем последний reel из БД
const { data: lastReel } = await supabase
  .from('laba_reels')
  .select('created_at')
  .eq('tracked_account_id', account.id)
  .order('created_at', { ascending: false })
  .limit(1)
  .single();

// Фильтруем только новые reels
const newReels = reelsData.filter(reel => {
  const reelDate = new Date(timestamp * 1000);
  return reelDate > lastReelDate;
});
```

Cron:
- ✅ Парсит 40 reels (чтобы найти новые)
- ✅ Фильтрует только те, которых нет в БД
- ✅ Добавляет ТОЛЬКО новые с плашкой "новое"
- ✅ Списывает 15 метакоинов за каждое новое видео

### 3. ✅ Хардкор экран при выходе назад из "отслеживаемые лаба"

**Проблема:** При нажатии кнопки "назад" появляется blur overlay с кнопкой "начать отслеживание", хотя аккаунты есть.

**Решение:** 
Заменил условие `accountRemoved` на `accounts.length === 0`:

**Файл:** `src/screens/laba-tracked/LabaTrackedScreen.tsx`

```typescript
// БЫЛО:
{accountRemoved && (
  <img src={blurOverlay} ... />
)}

// СТАЛО:
{accounts.length === 0 && !loading && (
  <img src={blurOverlay} ... />
)}
```

Теперь blur overlay показывается ТОЛЬКО когда реально нет аккаунтов, а не при удалении.

### 5. ✅ Кнопка "анализ" не видна на карточках

**Проблема:** Кнопка "анализ" на карточках reels не видна или не кликабельна.

**Причина:** Фоновый div с классом `blur-wave` блокировал pointer events.

**Решение:**
Добавил `pointerEvents: 'none'` к фоновому div:

```typescript
<div className="blur-wave" style={{
  position: 'absolute',
  inset: 0,
  backdropFilter: 'blur(50px)',
  background: '#000',
  border: '4px solid rgba(255, 255, 255, 0.3)',
  borderRadius: '30px',
  pointerEvents: 'none',  // ← ДОБАВЛЕНО
}} />
```

Кнопка "анализ" имеет `pointerEvents: 'auto'` и `zIndex: 999999`, поэтому теперь она кликабельна.

**Файл:** `src/components/ReelCard.tsx`
