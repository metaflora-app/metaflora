## 🔥 Что было исправлено:

### 1. Роутинг для премиум пользователей ✅

**Проблема:** После покупки подписки при следующем запуске показывались все онбординг экраны заново.

**Решение:**
- `SplashScreen` теперь проверяет `subscription_type`
- Если `premium` - сразу переход на `/main-dashboard-premium` через 3 секунды
- Если `free` - показывается обычный онбординг

### 2. Кеш баланса ✅

**Проблема:** `getOrCreateUser()` возвращал старое значение баланса из кеша, поэтому при покупке/трате использовались неправильные значения.

**Решение:**
- `getOrCreateUser()` теперь ВСЕГДА делает запрос к Supabase
- Никакого кеша - только свежие данные
- Добавлено логирование баланса при каждом запросе

### 3. Обновление баланса на главном экране ✅

**Проблема:** Баланс обновлялся раз в 10 секунд, поэтому после покупки/траты показывал старое значение.

**Решение:**
- Уменьшен интервал обновления с 10 секунд до 3 секунд
- Теперь баланс обновляется почти мгновенно
- Используется прямой запрос к Supabase для получения свежего баланса

### 4. Переменные баланса в транзакциях ✅

**Проблема:** Использовался `user.metacoins_balance` который мог быть устаревшим.

**Решение:**
- Сохраняем `currentBalance = user.metacoins_balance` в начале функции
- Используем `currentBalance` в `balance_before`
- Используем `newBalance` в `balance_after`
