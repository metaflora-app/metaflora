SELECT awaiting_time_input

## ⚠️ Если не работает

### Проблема 1: awaiting_time_input не создается
**Причина**: Колонка не добавлена в БД
**Решение**: Выполни SQL из `ADD_AWAITING_TIME_INPUT.sql`

### Проблема 2: notification_time не обновляется
**Причина**: Backend еще не задеплоился с новым кодом
**Решение**: Дождись деплоя (~2-3 минуты)

### Проблема 3: notifications_enabled не влияет на отправку
**Причина**: Cron проверяет настройки, но возможно запись не создана
**Решение**: Создай запись вручную:
```sql
INSERT INTO laba_notification_settings (user_id, tracked_account_id, notifications_enabled)
VALUES (
  (SELECT id FROM users WHERE telegram_id = 994500304),
  (SELECT id FROM laba_tracked_accounts WHERE instagram_username = 'mertzv2'),
  false
);
```
