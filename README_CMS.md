# 🎯 CMS МЕТАФЛОРА - БЫСТРЫЙ СТАРТ

## 📦 Что реализовано

**Система управления контентом** для добавления промптов, статей и уроков **БЕЗ работы в Figma**.

---

## 🚀 БЫСТРЫЙ СТАРТ

### 1. Зайти в CMS

```
URL: https://service-production-f0b1.up.railway.app/dashboard/content
Пароль: metaflora2026
```

### 2. Выбрать модуль

- **Цех** - промпты
- **Полигон** - статьи
- **Академия** - курсы и уроки

### 3. Заполнить форму

- Загрузить обложку (PNG/JPG, макс 5MB)
- Добавить текстовые данные
- Проверить live preview справа

### 4. Нажать "деплой"

Контент моментально сохраняется в Supabase и появляется в мини-аппе!
