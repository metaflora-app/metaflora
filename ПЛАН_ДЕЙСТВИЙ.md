### Шаг 3: Проверить Supabase RLS

1. Открыть Supabase Dashboard:
   - https://supabase.com/dashboard/project/lwjsbflvsmscfrdkejia

2. Перейти в SQL Editor:
   - https://supabase.com/dashboard/project/lwjsbflvsmscfrdkejia/sql/new

3. Выполнить проверку RLS:
   ```sql
   -- Проверить, включен ли RLS
   SELECT tablename, rowsecurity 
   FROM pg_tables 
   WHERE schemaname = 'public' AND tablename IN ('users', 'metacoins_transactions');
   ```

4. **Если RLS включен (rowsecurity = true):**
   - Вариант А: Отключить RLS (для отладки):
     ```sql
     ALTER TABLE users DISABLE ROW LEVEL SECURITY;
     ALTER TABLE metacoins_transactions DISABLE ROW LEVEL SECURITY;
     ```
   
   - Вариант Б: Настроить политики (безопасный):
     ```sql
     CREATE POLICY "Enable all for anon" ON users
     FOR ALL USING (true) WITH CHECK (true);
     
     CREATE POLICY "Enable all for anon" ON metacoins_transactions
     FOR ALL USING (true) WITH CHECK (true);
     ```

## 🐛 Если проблема не решена:

### Вариант 1: Логи показывают ошибки

1. Скопировать текст ошибок из консоли
2. Показать агенту - он поможет исправить

### Вариант 2: Логи не появляются

**Причина:** Код не выполняется  
**Решение:**
1. Проверить Railway логи - есть ли ошибки при сборке?
2. Проверить Network tab в DevTools - идут ли запросы к Supabase?

### Вариант 3: Логи показывают "No Telegram user ID"

**Причина:** Telegram WebApp не инициализирован  
**Решение:**
1. Открыть мини-апп через Telegram (не напрямую в браузере)
2. Или добавить fallback для тестирования:
   ```typescript
   export function getTelegramUserId(): number | null {
     if (typeof window !== 'undefined') {
       const telegram = (window as any).Telegram;
       if (telegram?.WebApp?.initDataUnsafe?.user?.id) {
         return telegram.WebApp.initDataUnsafe.user.id;
       }
       // Fallback для тестирования в браузере
       return 123456789;
     }
     return null;
   }
   ```

### Вариант 4: Логи показывают "Error updating balance" или "Error creating transaction"

**Причина:** Supabase RLS блокирует запросы  
**Решение:**
1. Выполнить SQL из файла `SUPABASE_FIX.sql`
2. Отключить RLS или настроить политики
