### 3. iPhone - видео и изображения не грузятся

**Проблема:** На iPhone видео показывает черный экран, изображения не грузятся

**Возможные причины:**
1. **Кэш iOS Safari** - попробовать добавить meta теги no-cache
2. **Формат видео** - MP4 должен быть с +faststart (moov atom в начале)
3. **CORS** - проверить headers Supabase Storage
4. **Размер** - видео может быть слишком большое для мобильного

**Решения:**
1. Добавить в index.html:
   ```html
   <meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate">
   <meta http-equiv="Pragma" content="no-cache">
   <meta http-equiv="Expires" content="0">
   ```

2. Конвертировать видео:
   ```bash
   ffmpeg -i input.mp4 -c copy -movflags +faststart output.mp4
   ```

3. Добавить обработчики ошибок:
   ```tsx
   <video
     onError={(e) => {
       console.error('Video error:', e);
       alert('Ошибка загрузки видео');
     }}
     onLoadStart={() => console.log('Video load start')}
     onLoadedData={() => console.log('Video loaded')}
   />
   ```

4. Для изображений:
   ```tsx
   <img
     loading="eager"
     crossOrigin="anonymous"
     referrerPolicy="no-referrer"
     onError={(e) => console.error('Image error:', e)}
   />
   ```

**Примечание:** Возможно проблема в кэше iOS - пользователь сказал "возможно у айфона и вообще мобильных устройств дело в кэше как то". Timestamp в API уже добавлен, может помочь.
