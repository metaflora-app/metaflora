# Проблема с Telegram уведомлениями - 2026-02-02 16:56

## ❌ Проблема

Backend возвращает `"sent": true`, но уведомления не приходят в Telegram.

## 🔍 Возможные причины

### 1. Неправильный chat_id (telegram_id)
Backend берет `telegram_id` из таблицы `users`:
```typescript
const userId = (account.users as any).telegram_id;
```

Telegram API возвращает ошибку `chat not found` если chat_id неверный.

### 2. Пользователь не запускал бота
Telegram бот НЕ МОЖЕТ отправлять сообщения пользователю, пока пользователь не запустил бота (`/start`).

**Решение**: Открой бота и нажми `/start` или любую кнопку.

### 3. Бот заблокирован пользователем
Если ты заблокировал бота - нужно разблокировать.

---

## 🔧 Как проверить

### Вариант 1: Проверить telegram_id в БД
```sql
SELECT telegram_id, username 
FROM users 
WHERE telegram_id IS NOT NULL
ORDER BY created_at DESC
LIMIT 5;
```

### Вариант 2: Проверить в мини-апе
1. Открой мини-апп
2. DevTools (F12) → Console
3. Выполни:
```javascript
window.Telegram.WebApp.initDataUnsafe.user.id
```

### Вариант 3: Проверить логи Railway
После деплоя с логированием:
```
Deploy Logs → поиск "Telegram API error"
```

Должно быть сообщение с chat_id и ошибкой.

## 🧪 Тестовая отправка

Попробуй отправить тестовое сообщение себе:

```bash
# Замени YOUR_TELEGRAM_ID на свой ID
curl -X POST "https://api.telegram.org/bot8435745315:AAHr5BCZDaHNG8m4joL6h6eYeBFmO0GYyzI/sendMessage" \
  -H "Content-Type: application/json" \
  -d '{
    "chat_id": YOUR_TELEGRAM_ID,
    "text": "тест",
    "parse_mode": "Markdown"
  }'
```

Если вернет `"ok": true` - сообщение должно прийти.
Если вернет `"chat not found"` - нужно запустить бота.
