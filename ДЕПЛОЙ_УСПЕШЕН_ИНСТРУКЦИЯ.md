### 2. Реализована обратная совместимость ✅

Мини-апп теперь работает в **ДВУХ РЕЖИМАХ**:

#### Режим 1: С content_blocks (новый формат)
```typescript
{
  content_blocks: [
    { id: '1', type: 'text', content: 'Текст статьи...' },
    { id: '2', type: 'image', content: 'https://...' },
    { id: '3', type: 'prompt', content: 'Промпт...' },
    { id: '4', type: 'materials', content: '5' }
  ]
}
```

#### Режим 2: Без content_blocks (старый формат)
```typescript
{
  content_text: 'Текст статьи...',
  prompt_text: 'Промпт...'
}
```

**Логика:** Если `content_blocks` пустой или null, создаются блоки из старых полей автоматически.

## 🚀 СЛЕДУЮЩИЙ ШАГ: ВЫПОЛНИТЬ SQL МИГРАЦИЮ

### ⚠️ КРИТИЧНО: Добавить колонку в Supabase

**Файл:** `SUPABASE_ADD_CONTENT_BLOCKS.sql`

**Где выполнить:**
1. Зайти в Supabase: https://supabase.com/dashboard/project/lwjsbflvsmscfrdkejia/sql/new
2. Скопировать содержимое файла `SUPABASE_ADD_CONTENT_BLOCKS.sql`
3. Выполнить SQL

**Что делает SQL:**
```sql
-- Добавляет колонку content_blocks
ALTER TABLE polygon_articles
ADD COLUMN IF NOT EXISTS content_blocks JSONB;

-- Создает индекс для быстрого поиска
CREATE INDEX IF NOT EXISTS idx_polygon_articles_content_blocks 
ON polygon_articles USING GIN (content_blocks);
```
