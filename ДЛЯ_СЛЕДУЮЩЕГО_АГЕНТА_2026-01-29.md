### Проблема №1: Видео не загружается на iPhone

**Описание:**
- Видео в academy-lesson-video не грузится на iOS (только на Mac)
- Показывается черный экран с паузой
- Нативные контролы мелкие

**Причина:**
- MP4 файл имеет неправильную структуру (moov atom в конце вместо начала)
- iOS Safari требует moov в начале файла

**Решение:**
Конвертировать видео с флагом `+faststart`:
```bash
ffmpeg -i input.mp4 -c copy -movflags +faststart output.mp4
```

Загрузить в Supabase Storage и использовать URL вместо локального файла.

**Файлы:**
- Локальное видео: `/Users/user/Desktop/метафлора/src/assets/test-video.mp4` (12MB)
- Исходник: `/Users/user/Desktop/для теста.mp4`
- Инструкция: `CONVERT_VIDEO_FOR_IOS.md`

- TypeScript ошибка: params должны быть Promise в Next.js 15
- Сборка падает, Railway не может задеплоить

**Ошибка:**
```
app/api/user/[id]/balance/route.ts
Type error: Route has an invalid "PATCH" export:
Type "{ params: { id: string; }; }" is not a valid type
```

**Решение:**
Либо удалить balance/route.ts, либо исправить на:
```typescript
export async function PATCH(
  request: NextRequest,
  context: { params: Promise<{ id: string }> }
) {
  const { id } = await context.params;
}
```

## ⚠️ КРИТИЧНЫЕ МОМЕНТЫ

### 1. Видео на iOS
- Локальные MP4 файлы не грузятся на iPhone в Telegram Mini App
- Нужно использовать внешний URL (Supabase Storage)
- Видео должно быть сконвертировано с `+faststart` флагом

### 2. Fullscreen видео
- Используется `window.Telegram.WebApp.requestFullscreen()` для API 8.0+
- Fallback: HTML5 `requestFullscreen()`
- Blur overlay с кнопкой плей, при клике - fullscreen

### 3. Отправка материалов
- **Академия:** `academy-lesson-materials` - реализовано с детальными ошибками
- **Полигон:** `article` - НЕ реализовано fullscreen изображения (откачено)
- **Сервис:** endpoint `/api/bot/send-materials` - sendDocument реализован, но сервис не деплоится

### 4. Деплой сервиса
- Railway падает из-за `balance/route.ts` (TypeScript ошибка)
- Нужно удалить этот файл или исправить async params
- Текущий active deployment: старая версия без sendDocument
