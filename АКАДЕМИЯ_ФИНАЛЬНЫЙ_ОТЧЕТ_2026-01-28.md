## 🔧 КРИТИЧНЫЕ МОМЕНТЫ

### 1. ⚠️ is_active флаг

**ВАЖНО:** Уроки создаются с `is_active: false` и активируются только при деплое!

**Почему это важно:**
- Маленькая карточка создает урок → `is_active: false`
- Урок НЕ показывается в мини-аппе
- Пользователь добавляет видео → урок всё еще `is_active: false`
- Пользователь заполняет большую карточку → урок всё еще `is_active: false`
- Пользователь нажимает ДЕПЛОЙ → `is_active: true` ← ТОЛЬКО ЗДЕСЬ!
- Урок появляется в мини-аппе (полностью готовый)

### 2. ⚠️ Async/await в academy-video

В `academy-video` кнопка "карточка" должна быть async:

```typescript
onClick={async () => {
  await handleSave(); // Ждем сохранения!
  window.location.href = '/dashboard/content/academy-card-large';
}}
```

Без `await` данные не успеют сохраниться!

### 3. ⚠️ Materials в content_blocks

В `academy-card-large` перед деплоем:

```typescript
let finalContentBlocks = [...contentBlocks];
if (materials.length > 0) {
  finalContentBlocks.push({
    id: Date.now().toString(),
    type: 'materials',
    content: JSON.stringify(materials), // JSON строка!
  });
}
// Отправить finalContentBlocks, НЕ contentBlocks!
```

### 4. ⚠️ Система прогресса

**localStorage ключи:**
- `academy-lessons-progress` - объект {lessonId: {videoWatched, materialsRead}}
- `academy-lessons-completed` - массив [lessonId1, lessonId2]

**Условия:**
- Видео: досмотр до **80%** → videoWatched
- Материалы: скролл до **95%** ИЛИ нет скролла → materialsRead
- Оба TRUE → урок в completed

**Демо НЕ учитывается:**
```typescript
if (lessonType !== 'academy') return; // Игнорировать demo
```
