# Реферальная программа МЕТАФЛОРА* нейро

## Что получает пользователь

Каждый зарегистрированный пользователь получает персональную ссылку:

```text
https://t.me/neuro_metaflora_bot?start=ref_mishchenko_is_K7m4Q2x9Qa
```

В ссылке есть ник пригласившего и случайный код. Ник нужен для читаемости, а привязка в базе происходит по коду. Telegram ID в ссылке не публикуется. Смена ника не ломает ранее созданную ссылку.

Человек, который впервые открыл бота по такой ссылке, закрепляется за пригласившим навсегда. Повторный переход по другой ссылке не меняет привязку. Саморефералы и неизвестные коды отклоняются.

## Денежное вознаграждение

Пригласивший получает процент с каждого подтверждённого пополнения прямого реферала:

| Уровень | Условие | Вознаграждение |
| --- | ---: | ---: |
| классика | доступна сразу | 25% |
| серебро | 3 оплативших реферала | 30% |
| золото | 10 оплативших рефералов | 35% |
| платина | 25 оплативших рефералов | 40% |

Оплатившим считается человек, который хотя бы один раз пополнил баланс. Учитывается количество разных пользователей, а не число их платежей.

Новый уровень начинает действовать на платеже, который помог его получить. Например, первая оплата третьего реферала уже приносит 30%.

Достигнутый уровень сохраняется. Вознаграждение начисляется с каждого следующего пополнения прямого реферала.

## Бонус метакоинами для двоих

После первого пополнения реферал получает ещё 25% метакоинами. Одновременно пригласившему открывается бонус `+25%` к его следующему пополнению.

Пример:

1. Друг пополняет баланс на 2 000 метакоинов и получает 2 500.
2. Пригласивший получает денежное вознаграждение по своему уровню.
3. При следующем собственном пополнении на 4 000 метакоинов пригласивший получает 5 000.

Ограничения по сумме пополнения нет. Каждый новый оплативший реферал создаёт отдельный бонус для пригласившего. Бонусы сохраняются в очереди и применяются по одному к следующим пополнениям, поэтому несколько приглашений не складываются в `+50%` или `+75%` на одной оплате.

Повторные платежи реферала продолжают приносить денежное вознаграждение, но больше не создают бонус за первое пополнение.

## Начисления и вывод

После подтверждения платежа денежное вознаграждение получает статус «в обработке». Когда заканчивается период проверки и возврата, сумма становится доступна для вывода.

Минимальная сумма вывода составляет 1 000 ₽. Внутренняя конвертация партнёрского дохода в метакоины не используется.

Заявка оформляется внутри Telegram:

1. Пользователь открывает раздел «вывести средства».
2. Отправляет сумму одним сообщением.
3. Отправляет номер телефона для СБП, номер карты или адрес USDT TRC-20.
4. Бот резервирует сумму и создаёт заявку со статусом «в обработке».

После создания заявки бот отправляет владельцу отдельную карточку с суммой и реквизитами. Владелец сначала делает перевод через согласованный банк или криптосервис, затем нажимает «выплачено». Кнопка повторно не списывает деньги. При отклонении заявки резерв возвращается в доступный баланс партнёра.

Автоматический перевод пока не заявляется: для него нужно выбрать payout-провайдера отдельно для СБП/карт и USDT TRC-20, подтвердить договор и добавить production-ключи. Пока этого выбора нет, ручная карточка владельца — единственный честный маршрут выплаты.

## Кабинет в Telegram

Главный экран показывает:

- уровень и текущую ставку;
- прогресс до следующего уровня;
- персональную ссылку;
- количество приглашённых и оплативших;
- общий оборот рефералов;
- доступную сумму, деньги в обработке и заработок за всё время;
- число доступных бонусов `+25%`.

Кнопки кабинета:

```text
[ поделиться ссылкой ]
[ мои рефералы ] [ начисления ]
[ уровни и условия ]
[ вывести средства ]
[ профиль ]
[ назад ] [ главное меню ]
```

Раздел «мои рефералы» показывает ник, статус первой оплаты и оборот каждого приглашённого. Раздел «начисления» показывает сумму платежа, ставку, вознаграждение и его статус.

## Защита от двойных начислений

Каждый платёж передаётся в реферальную систему с уникальным `paymentId`. Повторная доставка события с тем же идентификатором не меняет баланс и не создаёт ещё одно начисление.

Денежные суммы хранятся целыми копейками. Метакоины хранятся целыми единицами. Все изменения одного платежа выполняются в транзакции SQLite: запись платежа, бонус рефералу, бонус пригласившему и денежное начисление либо сохраняются вместе, либо полностью откатываются.

## Подключение настоящей оплаты

Платёжный обработчик должен зарегистрировать пользователя и один раз вызвать:

```js
referralService.recordPayment({
  paymentId: payment.id,
  telegramId: payment.telegramUserId,
  amountKopecks: payment.amountKopecks,
  baseMetacoins: payment.metacoins,
  confirmedAt: payment.confirmedAt
});
```

Метод уже реализован и вызывается после подтверждённого платежа YooKassa. Начисления удерживаются до окончания периода проверки, после чего отдельный фоновый worker переводит их в доступные. Заявка на вывод всё равно требует фактического перевода владельцем или подключённым payout-провайдером.

Период удержания задаётся переменной `REFERRAL_HOLD_DAYS`, по умолчанию три дня. Путь к общей базе задаётся через `APP_DATABASE_PATH`. В Railway используется `/data/metaflora.sqlite`.

## Таблицы SQLite

- `referral_users`: пользователи, коды, пригласивший и баланс метакоинов;
- `referral_payments`: подтверждённые платежи;
- `referral_boosts`: бонусы `+25%` для следующих пополнений;
- `referral_earnings`: денежные начисления;
- `referral_withdrawals`: заявки на вывод.
- `promo_metacoin_grants`: идемпотентные начисления по промокодам.

База работает в режиме WAL с включёнными внешними ключами и полными синхронными записями.
