# Экономика метакоинов

Метакоин — единая расчётная единица в боте. Цена запуска рассчитывается по действующему маршруту и текущей цене RouterAI либо по специальному маршруту Polza. Тариф лишь определяет, сколько метакоинов получает пользователь за оплату.

## Распределение рублёвой оплаты

Каждая подтверждённая рублёвая оплата распределяется так:

| Направление | Доля от валовой суммы | Что покрывает |
|---|---:|---|
| Комиссия платежа | 3,5% | Эквайринг |
| Polza | 6% | Suno и Topaz; деньги копятся в отдельном резерве и пополняются worker-ом по правилам Polza |
| RouterAI | 50,5% | Все обычные маршруты RouterAI |
| Доля владельца | 40% | До реферального обязательства |

Внутри 50,5% RouterAI заложен хвост 2% поверх максимальной подтверждённой себестоимости каждого списания. База на вызовы равна 50,5% / 1,02, то есть примерно 49,51% валовой оплаты, хвост — около 0,99%. Это один бюджет RouterAI, второго полного баланса под того же пользователя больше нет.

Реферальное начисление фиксируется отдельным обязательством и вычитается из доли владельца. Поэтому 40% относятся к продаже без реферала; при реферальной выплате реальная доля владельца ниже на сумму этого обязательства.

## Проверка покрытия

`src/finance-ledger.js` создаёт реальные строки `gross → payment_fee → api_reserve.polza → api_reserve.routerai → owner_share`. Для пакетов и тарифов с выданными метакоинами он считает худший публичный курс и отказывается создать распределение, если RouterAI не получает полную базовую ответственность вместе с хвостом.

Отчёт строится этим же кодом, а не вручную:

```sh
node scripts/report-pricing-economics.mjs
```

Тест `test/pricing-economics-report.test.js` проверяет все четыре пакета и восемь тарифных предложений. Для «исследователь · 3 месяца» остаток после хвоста равен нулю: этот продукт покрывает расчёт, но не имеет дополнительного запаса сверх уже включённого 2% хвоста.

## Правила ценообразования моделей

1. Для RouterAI цена берётся из публичного `/api/v1/models` и рассчитывается по настоящей единице тарификации маршрута: запросу, секунде, символу, токенам, выходным image-токенам либо мегапикселям.
2. Для Suno и Topaz остаётся подтверждённый специальный маршрут Polza. Эти модели не финансируются резервом RouterAI.
3. Цена в метакоинах округляется вверх так, чтобы при самом дешёвом тарифе покрыть стоимость провайдера и RouterAI-хвост внутри установленной политики.
4. `usage.cost` из ответа RouterAI сохраняется в безопасной истории завершённой генерации. Это позволяет сверять реальную фактическую стоимость с расчётной, не меняя списание пользователя после запуска.

Публичные данные RouterAI пока не публикуют верхнюю границу output image tokens для MAI Image 2.5 и MAI Image 2.5 Pro. У этих двух карточек сохраняется фактическая стоимость ответа; их максимальный тариф нужно подтвердить с RouterAI до объявления математически гарантированной верхней границы.

## Криптооплата

Для Base USDC в конфигурации каждого продукта указан отдельный разовый маршрут. В нём есть минимум 5,25 USDC на пополнение OpenRouter, резерв сети и доля владельца. Накопительного пополнения из нескольких оплат нет. Все текущие пакеты и тарифы превышают этот минимум.

## Что проверяется до релиза

- публичный RouterAI-снимок содержит не менее 400 ценовых записей;
- у каждого опубликованного маршрута есть совместимый API-контракт и цена;
- цены моделей, инструментов и агентов проходят экономический аудит;
- все 12 публичных продуктов покрывают RouterAI-базу и 2% хвост;
- офлайн-проверки не создают оплат, генераций или provider funding.
