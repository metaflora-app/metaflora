# ИСПРАВЛЕНИЕ ОТПРАВКИ ФАЙЛОВ В TELEGRAM

**Дата:** 2026-01-29  
**Проблема:** При нажатии "скачать файлы" приходят ссылки на Supabase, а не сами файлы  
**Решение:** Использовать `sendDocument` вместо `sendMessage` в Telegram Bot API

---

## ⚠️ ЧТО УЖЕ ИСПРАВЛЕНО В МИНИ-АППЕ

✅ **Безопасный рендеринг блоков** - если materials сломан, остальные блоки (text, image, prompt) продолжат работать  
✅ **Ебанутый парсинг materials** - обрабатывает ВСЕ edge cases:
- Пустые значения (null, undefined, "")
- Невалидный JSON
- Одиночный объект вместо массива
- Пустой массив
- Отсутствие url/name в элементах

**Файл:** `src/screens/academy-lesson-materials/AcademyLessonMaterialsScreen.tsx`

## 🔧 ЧТО НУЖНО ИСПРАВИТЬ В СЕРВИСЕ

### Файл: `/Users/user/Desktop/metaflora-service/app/api/bot/send-materials/route.ts`

**ПОЛНОСТЬЮ ЗАМЕНИТЬ** на этот код:

```typescript
import { NextRequest, NextResponse } from 'next/server';

export async function POST(request: NextRequest) {
  try {
    const { materials, lessonTitle, userId } = await request.json();
    
    const botToken = process.env.TELEGRAM_BOT_TOKEN;
    
    // 1. Проверка токена
    if (!botToken) {
      console.error('[BOT] TELEGRAM_BOT_TOKEN not configured');
      return NextResponse.json({ 
        success: false, 
        error: 'Bot token not configured (contact admin)' 
      }, { status: 500 });
    }
    
    // 2. Проверка userId
    if (!userId || userId === 'unknown' || userId === null) {
      console.error('[BOT] Invalid userId:', userId);
      return NextResponse.json({ 
        success: false, 
        error: 'User ID not available (open from Telegram)' 
      }, { status: 400 });
    }
    
    // 3. Проверка materials
    if (!materials || !Array.isArray(materials)) {
      console.error('[BOT] Invalid materials:', typeof materials);
      return NextResponse.json({ 
        success: false, 
        error: 'Invalid materials format' 
      }, { status: 400 });
    }
    
    if (materials.length === 0) {
      console.error('[BOT] Empty materials array');
      return NextResponse.json({ 
        success: false, 
        error: 'No files to send' 
      }, { status: 400 });
    }
    
    console.log('[BOT] Starting send:', {
      userId,
      lessonTitle,
      filesCount: materials.length,
      files: materials.map(m => ({ name: m.name, hasUrl: !!m.url }))
    });
    
    // 4. Отправить заголовок сообщения
    try {
      const headerResponse = await fetch(
        `https://api.telegram.org/bot${botToken}/sendMessage`,
        {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({
            chat_id: userId,
            text: `📎 *${lessonTitle}*\n\nМатериалы урока (${materials.length} файлов):`,
            parse_mode: 'Markdown'
          })
        }
      );
      
      if (!headerResponse.ok) {
        const error = await headerResponse.json();
        console.error('[BOT] Header send failed:', error);
      }
    } catch (headerError: any) {
      console.error('[BOT] Header error:', headerError.message);
      // Продолжаем даже если заголовок не отправился
    }
    
    // 5. Отправить КАЖДЫЙ файл через sendDocument
    const results = [];
    let successCount = 0;
    
    for (let i = 0; i < materials.length; i++) {
      const material = materials[i];
      
      // Валидация материала
      if (!material || typeof material !== 'object') {
        console.error(`[BOT] File ${i}: invalid format`);
        results.push({
          index: i,
          name: 'unknown',
          success: false,
          error: 'Invalid file format'
        });
        continue;
      }
      
      if (!material.url || typeof material.url !== 'string') {
        console.error(`[BOT] File ${i}: missing URL`);
        results.push({
          index: i,
          name: material.name || 'unknown',
          success: false,
          error: 'Missing file URL'
        });
        continue;
      }
      
      const fileName = material.name || `file_${i + 1}`;
      const fileSize = material.size || '';
      
      try {
        console.log(`[BOT] Sending file ${i + 1}/${materials.length}:`, fileName);
        
        // КРИТИЧНО: используем sendDocument для отправки ФАЙЛА, а не ссылки
        const docResponse = await fetch(
          `https://api.telegram.org/bot${botToken}/sendDocument`,
          {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({
              chat_id: userId,
              document: material.url, // URL файла из Supabase Storage
              caption: `📄 ${fileName}${fileSize ? ` (${fileSize})` : ''}`,
              parse_mode: 'Markdown'
            })
          }
        );
        
        const docResult = await docResponse.json();
        
        if (docResponse.ok && docResult.ok) {
          console.log(`[BOT] File ${i + 1} sent successfully:`, fileName);
          successCount++;
          results.push({
            index: i,
            name: fileName,
            success: true,
            telegram_file_id: docResult.result?.document?.file_id
          });
        } else {
          console.error(`[BOT] File ${i + 1} send failed:`, docResult);
          results.push({
            index: i,
            name: fileName,
            success: false,
            error: docResult.description || 'Telegram API error',
            error_code: docResult.error_code
          });
        }
        
      } catch (fileError: any) {
        console.error(`[BOT] File ${i + 1} exception:`, fileError.message);
        results.push({
          index: i,
          name: fileName,
          success: false,
          error: fileError.message || 'Network error'
        });
      }
      
      // Пауза между файлами (избежать rate limit)
      if (i < materials.length - 1) {
        await new Promise(resolve => setTimeout(resolve, 300));
      }
    }
    
    // 6. Итоговый результат
    const failedCount = results.length - successCount;
    
    console.log('[BOT] Send completed:', {
      total: materials.length,
      success: successCount,
      failed: failedCount
    });
    
    return NextResponse.json({
      success: successCount > 0,
      message: failedCount === 0
        ? `Все файлы отправлены (${successCount})`
        : `Отправлено ${successCount} из ${materials.length} файлов`,
      stats: {
        total: materials.length,
        success: successCount,
        failed: failedCount
      },
      results
    });
    
  } catch (error: any) {
    console.error('[BOT] Critical error:', error);
    return NextResponse.json({
      success: false,
      error: error.message || 'Internal server error',
      stack: process.env.NODE_ENV === 'development' ? error.stack : undefined
    }, { status: 500 });
  }
}
```

```typescript
sendMessage({
  text: "📄 file.pdf\n🔗 https://supabase.co/storage/..."
```

```typescript

  document: "https://supabase.co/storage/...",
  caption: "📄 file.pdf"
})
```
✅ **Результат:** В Telegram приходит САМ ФАЙЛ, который можно скачать

## 📋 ОБРАБОТАННЫЕ EDGE CASES

### В мини-аппе (фронтенд):
1. ✅ materials блок отсутствует
2. ✅ materials.content = null/undefined
3. ✅ materials.content = "" (пустая строка)
4. ✅ materials.content = "[]" (пустой массив)
5. ✅ materials.content невалидный JSON
6. ✅ materials.content парсится, но не массив
7. ✅ Элементы массива без url/name
8. ✅ Telegram userId недоступен
9. ✅ Другие блоки (text, image, prompt) НЕ ломаются при ошибке в materials

### В сервисе (бэкенд):
1. ✅ TELEGRAM_BOT_TOKEN отсутствует
2. ✅ userId невалиден (null, undefined, "unknown")
3. ✅ materials не массив
4. ✅ materials пустой массив
5. ✅ Файл без URL
6. ✅ Telegram API падает при отправке
7. ✅ Частичная отправка (некоторые файлы не отправились)
8. ✅ Rate limiting (пауза 300мс между файлами)
9. ✅ Детальные логи для отладки
