## 🔘 Шаг 3: Тестируй кнопки

### Кнопка 1: "отключить уведомления"

**Что должно произойти**:
1. Нажимаешь кнопку
2. Приходит сообщение: "уведомления для этого аккаунта отключены. вы можете включить их обратно в мини-приложении"

**Проверка в Supabase**:
```sql
SELECT notifications_enabled 
FROM laba_notification_settings
WHERE tracked_account_id = (SELECT id FROM laba_tracked_accounts WHERE instagram_username = 'mertzv2')
AND user_id = (SELECT id FROM users WHERE telegram_id = 994500304);
```
**Результат**: `false`

**Проверка работы**:
Запусти снова:
```bash
curl https://service-production-f0b1.up.railway.app/api/cron/send-notifications
```
Уведомление для @mertzv2 НЕ должно прийти (будет "sent": false, "reason": "уведомления отключены").

---

### Кнопка 2: "изменить время отправки уведомления"

**Что должно произойти**:
1. Нажимаешь кнопку
2. Приходит: "напишите время в формате ЧЧ:ММ..."

**Проверка в Supabase**:
```sql
SELECT awaiting_time_input 
FROM laba_notification_settings
WHERE tracked_account_id = (SELECT id FROM laba_tracked_accounts WHERE instagram_username = 'mertzv2')
AND user_id = (SELECT id FROM users WHERE telegram_id = 994500304);
```
**Результат**: `true`

3. Пишешь "09:00" в бота
4. Приходит: "время уведомлений изменено на 09:00 по московскому времени"

**Проверка в Supabase**:
```sql
SELECT notification_time, awaiting_time_input 
FROM laba_notification_settings
WHERE tracked_account_id = (SELECT id FROM laba_tracked_accounts WHERE instagram_username = 'mertzv2')
AND user_id = (SELECT id FROM users WHERE telegram_id = 994500304);
```
**Результат**: `notification_time = '09:00:00'`, `awaiting_time_input = false`

## ⚠️ Если не работает

### Кнопки не реагируют
- Проверь логи Railway → Deploy Logs → поиск "webhook получен"
- Webhook должен получать callback_query

### Время не сохраняется
- Проверь что колонка `awaiting_time_input` существует в БД
- Выполни SQL из `ADD_AWAITING_TIME_INPUT.sql`

### Уведомления все равно приходят
- Проверь что `notifications_enabled = false` в БД
- Проверь логи: должно быть "🔕 Уведомления отключены для @username"
