## ⚠️ Плашки "новое" не показываются

### Проблема
Frontend получает данные с `isNew: true` из backend (строка 89 в `tracked-reels/route.ts`), но плашки не отображаются.

### Возможные причины

1. **Кэш браузера**
   - Frontend кэширует данные в sessionStorage
   - Нужен хардрефреш или очистка кэша

2. **Данные не обновляются**
   - Reels загружаются один раз при первом заходе
   - Нужно обновить экран или перезайти

3. **SQL миграция не выполнена**
   - Колонки `is_new` и `marked_new_at` могут отсутствовать в БД

### Проверка в Supabase

```sql
-- Проверить что колонки существуют
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'laba_reels' 
AND column_name IN ('is_new', 'marked_new_at');

-- Проверить данные
SELECT 
  id, 
  instagram_reel_id, 
  account_username,
  is_new, 
  marked_new_at, 
  created_at
FROM laba_reels
WHERE tracked_account_id IS NOT NULL
AND is_new = true
ORDER BY created_at DESC
LIMIT 20;
```

Если колонок нет - выполнить миграцию:
```sql
ALTER TABLE laba_reels ADD COLUMN IF NOT EXISTS is_new BOOLEAN DEFAULT false;
ALTER TABLE laba_reels ADD COLUMN IF NOT EXISTS marked_new_at TIMESTAMP;
CREATE INDEX IF NOT EXISTS idx_laba_reels_is_new ON laba_reels(is_new) WHERE is_new = true;
```

## 🔍 Как проверить плашки

### Вариант 1: Хардрефреш
1. Открыть мини-апп
2. Перейти в Лаба → Отслеживаемые
3. Сделать хардрефреш (Cmd+Shift+R или очистить кэш)
4. Проверить что плашки "новое" появились

### Вариант 2: Проверить данные напрямую
```bash

curl "https://service-production-f0b1.up.railway.app/api/laba/tracked-reels?accountId=ACCOUNT_ID&userId=USER_ID"
```

1. Открыть DevTools (F12)
2. Network → найти запрос к `/api/laba/tracked-reels`
3. Проверить Response → должны быть reels с `"isNew": true`
4. Console → проверить что нет ошибок
