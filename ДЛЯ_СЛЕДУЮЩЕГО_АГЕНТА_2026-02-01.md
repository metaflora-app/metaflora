## ⚠️ ЧТО НУЖНО СДЕЛАТЬ

### 1. Запустить SQL миграцию в Supabase

Открыть Supabase → SQL Editor → Выполнить `SUPABASE_ADD_COLUMNS.sql`:

```sql
ALTER TABLE laba_reels ADD COLUMN IF NOT EXISTS is_new BOOLEAN DEFAULT false;
ALTER TABLE laba_reels ADD COLUMN IF NOT EXISTS marked_new_at TIMESTAMP;
CREATE INDEX IF NOT EXISTS idx_laba_reels_is_new ON laba_reels(is_new) WHERE is_new = true;
CREATE INDEX IF NOT EXISTS idx_laba_reels_marked_new_at ON laba_reels(marked_new_at) WHERE is_new = true;
```

### 2. Настроить Cron на Railway

**Вариант A: Railway Cron Jobs**
1. Railway Dashboard → metaflora-service → Settings
2. Cron Jobs → Add
3. Schedule: `0 5 * * *` (каждый день в 5:00 UTC = 8:00 МСК)
4. Command: `curl https://service-production-f0b1.up.railway.app/api/cron/update-tracked-reels`

**Вариант B: Внешний cron-job.org**
1. Зарегистрироваться на https://cron-job.org
2. Добавить job:
   - URL: `https://service-production-f0b1.up.railway.app/api/cron/update-tracked-reels`
   - Schedule: `0 5 * * *`

### 3. Проверить деплой

Подождать 3-4 минуты после последнего push, затем:
1. Открыть https://web-production-fc84.up.railway.app

## 🐛 Известные проблемы

### 1. Кнопки могут быть не видны сразу после деплоя

**Причина**: Railway кэширует старую версию

**Решение**: Хардрефреш (Cmd+Shift+R) или подождать 5 минут

### 2. Плашка "новое" не появляется

**Причина**: SQL миграция не выполнена в Supabase

**Решение**: Запустить `SUPABASE_ADD_COLUMNS.sql`

### 3. Cron не запускается

**Причина**: Не настроен на Railway или cron-job.org

**Решение**: Следовать инструкции `CRON_SETUP_RAILWAY.md`
