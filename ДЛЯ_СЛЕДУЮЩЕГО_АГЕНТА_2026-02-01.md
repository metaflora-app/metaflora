## ⚠️ ИЗВЕСТНЫЕ ПРОБЛЕМЫ (возможно нужно проверить)

### 1. Top-reels могут не отображаться
**Причина**: Возможно нужно запустить cron через кнопку в `/dashboard/laba`
**Решение**: 
- Зайти на https://service-production-f0b1.up.railway.app/dashboard/laba
- Нажать кнопку "🔄 обновить топ-рилс"
- Подождать 10-20 секунд
- Проверить в Supabase: таблица `laba_top_reels` должна содержать записи

**SQL для проверки**: `CHECK_TOP_REELS_DEBUG.sql` в корне backend

### 2. Изображения в материалах могут не грузиться
**Причина**: CORS или неправильные URL в Supabase
**Что проверить**:
- URL должны быть из Supabase Storage bucket `materials`
- Формат: `https://lwjsbflvsmscfrdkejia.supabase.co/storage/v1/object/public/materials/...`
- В коде используется `crossOrigin="anonymous"`

### 3. Видео в уроках
**Файл**: `AcademyLessonVideoScreen.tsx`
**Логика**: Загружается через `getAcademyVideos(lessonId)`
**Что проверить**: 
- Таблица `academy_videos` должна содержать записи с правильным `lesson_id`
- `video_url` должен быть из Supabase Storage bucket `academy-videos`
