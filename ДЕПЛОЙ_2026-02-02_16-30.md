## ⚠️ Проблема с плашками "новое"

Frontend НЕ показывает плашки "новое" на reels.

### Возможные причины

1. **Backend возвращает данные правильно** ✅
   - API `/api/laba/tracked-reels` возвращает `isNew: true`
   - Логика в `route.ts` строка 89: `isNew: reel.is_new || false`

2. **Frontend получает данные** ✅
   - `ReelCard.tsx` строка 97: `{reel.isNew && ...}`
   - Плашка должна показываться если `reel.isNew === true`

3. **Возможная проблема**: Кэш или данные не обновляются
   - Frontend кэширует reels в sessionStorage
   - Нужен хардрефреш или очистка кэша

### Проверка

1. **Проверить в DevTools**:
   ```
   Network → /api/laba/tracked-reels → Response
   Найти reels с "isNew": true
   ```

2. **Проверить в Console**:
   ```javascript
   // Очистить кэш
   sessionStorage.clear();
   // Перезагрузить
   location.reload();
   ```

3. **Проверить в Supabase**:
   ```sql
   SELECT id, instagram_reel_id, account_username, is_new, marked_new_at
   FROM laba_reels
   WHERE tracked_account_id IS NOT NULL
   AND is_new = true
   ORDER BY created_at DESC
   LIMIT 10;
   ```
